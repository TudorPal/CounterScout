# FACEIT downloads and imports

Reload **CounterScout — FACEIT Bridge** at `chrome://extensions` after updating its folder. This version is **0.4.0**. Refresh open FACEIT tabs too.

1. Run CounterScout. Pair the extension using the code in **Import**.
2. Check **Enable team sync and automatic demo imports**, then **Save & connect**.
3. Open a FACEIT match room and choose **Sync current FACEIT page** in the extension.
4. Review/edit the team names and rosters before confirming.
5. Either check **Download all available map demos after syncing this match room**, or confirm and click FACEIT’s normal **Download demo** button yourself for each played map.

The optional download checkbox works with one map or a multi-map series. It is unavailable on a team-history page. Only demo links actually supplied by FACEIT are downloaded; login/consent or unavailable links may require manual downloading.

Downloads must finish before parsing starts. CounterScout’s **Imports** menu shows queued/analysing status, and a completion notification offers **Open replay**. You can navigate elsewhere while waiting. Keep CounterScout running; an interrupted Chrome download can be resumed in Chrome Downloads.
