# CounterScout 1.5.0 — Windows portable

## What's new

- Detailed team scouting notes by T/CT and buy type: setup, timed moves, utility support, roles/possible lurks, distinct plans and round links.
- A scan-friendly AI match snapshot with short bullets instead of an essay.
- Later-round and sampled post-plant movement evidence; more balanced example selection across round types.
- **Settings → AI analysis** to add, replace or remove your own key without restarting. Evidence analysis still works without AI.

## Start

1. Download **CounterScout-1.5.0-windows-x64.zip** from the release's Assets.
2. Extract the entire ZIP to a writable folder, then run `CounterScout.exe`. Keep its console open; Ctrl+C stops it. The app opens in your browser; no Python or Node installation is needed.
3. For an update, copy your existing **user-data** folder into the new release folder. Never share this folder: it may contain API keys and private demos.
4. Optional AI: create your own free key at [Groq](https://console.groq.com/keys), keep the Free plan, then save it under **Settings → AI analysis**. Choose a team in Replay → AI Recap or Anti-Strat, build evidence, allow the compact evidence upload and generate the report. The ZIP does not include the developer's key.

## FACEIT extension

1. In Chrome, open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the release's `browser-extension` folder. For an existing installation, reload it; if its path points at an older release, remove/re-add it from the new folder.
2. Keep CounterScout running. In **Import**, configure the downloads folder and pair the extension using the app's pairing code.
3. Stay signed in to FACEIT. Open the match room, use **Sync current FACEIT page** and review the team names.
4. Tick **Enable team sync** for automatic demo import, then **manually click Download demo in the FACEIT match room**. Download each available map demo for a multi-map match. CounterScout imports and parses the downloaded files; progress and replay links appear in the app.

## Notes

AI tactics are interpretations, not guaranteed facts. Buy classifications, callout proximity and possible lurks are estimates; counterplay suggestions are labelled hypotheses. Verify cited rounds.

This ZIP is currently **unsigned** and may trigger a Windows warning. Only use downloads you trust; do not disable Windows security features. See the [signing guide](../windows-signing.md) for the maintainer's signing process.
