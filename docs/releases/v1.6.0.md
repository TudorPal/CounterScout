# CounterScout 1.6.0 — Windows portable

## What changed

- Compact, centered main navigation; page-specific actions stay in their workspaces. Settings and import notifications are available everywhere, including the replay's left sidebar.
- FACEIT extension setup moved into Settings. Import opens on FACEIT, with 25 matches per page and lightweight status polling.
- Import notifications show team names, progress and replay links, with five recent entries per page. Dismissing a notification preserves history. Upload ETA appears only when measurable.
- Round Utility, Utility Heatmap and Movement Patterns are separate replay navigation entries. Utility Heatmap shows grenade landings; Player Positions remains available for position-density heatmaps.
- Consistent multi-select Smoke / Flash / HE / Molotov / Decoy filters, matching radar padding, and no duplicate buy-phase economy strip. The top round strip controls round focus; aggregate views can show all rounds.
- UI polish: readable sidebar labels, persistent navigation while player profiles load, compact import status entries and reduced-motion support.

## Quick start

1. Download **CounterScout-1.6.0-windows-x64.zip** and extract the entire archive into a writable folder.
2. Run **CounterScout.exe**. No Python, Node or installation is needed.
3. The app opens at **http://127.0.0.1:5173**. Keep the launcher open; **Ctrl+C** stops it.
4. For optional AI analysis, open **Settings → AI analysis**, enter your own Groq key and save. No private API key is included in the ZIP.

## FACEIT automatic import

1. In Chrome, open `chrome://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and select the bundle's **browser-extension** folder.
3. Open CounterScout **Settings → FACEIT extension**. Copy the pairing code and check the monitored Downloads folder.
4. In the extension, enter the code, check **Enable team sync**, then save/connect.
5. Stay signed in to FACEIT. Open a match room, click **Sync current FACEIT page**, and review/confirm team names.
6. Manually click the demo download in the FACEIT room. Each downloaded map is imported automatically; repeat for each map in a series. Follow the notification bell for status and a Replay link.

## Updating

Extract the new bundle into a separate folder, then copy your existing **user-data** folder into it. Do not run old and new copies together. Reload the extension from the new bundle folder; verify pairing and team sync.
