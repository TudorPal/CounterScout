# CounterScout 1.5.1

- Shared Settings and import-notification icons on every main page; inside the replay workspace they live in the left navigation, not over the radar/scoreboard.
- Consistent Settings action sizes; FACEIT extension pairing/downloads folder moved here, with demo linking last.
- Import opens on FACEIT by default. Its library shows 25 matches per page; filters reset paging. Status-only polling avoids repeatedly transferring the match list.
- Import history includes recent extension jobs, active progress, failures and completed-demo replay links. Dismissing a toast keeps the history entry. Estimated remaining upload time appears only when transfer progress supports it; parsing has no reliable ETA.
- The top Insights round strip is the only round picker. Heatmap/Patterns begin on all rounds: select a round to focus it, select it again (or All rounds) to clear. Round Utility remains a single-round view.

This is a source update; the existing 1.5.0 portable ZIP is unchanged.
Upstream permission remains unresolved; see [credits](../credits.md) before distributing derivative source or binaries.
