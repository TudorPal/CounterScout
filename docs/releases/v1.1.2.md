## CounterScout v1.1.2 — Windows Portable

CS2 demo analysis in your browser: replays, grenade lineups, heatmaps and opponent scouting.

This release fixes FACEIT knife-round detection, including bayonet kills, and removes pre-match warmup events that caused incorrect scores and overtime timelines.

### Quick start

1. Download `CounterScout-1.1.2-windows-x64.zip` from **Assets** below.
2. Extract the entire ZIP into a writable folder.
3. Run `CounterScout.exe`. The app opens in your browser—no Python, Node or installation required.
4. Keep the launcher window open. Press **Ctrl+C** to stop the app.

### FACEIT automatic imports — Chrome

1. Open `chrome://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and select the extracted `browser-extension` folder.
3. Open CounterScout in Chrome at `http://127.0.0.1:5173`, then go to **Import → Extension setup & monitored folder**.
4. Set Chrome’s download folder and click **Save folder**.
5. Copy the pairing code into the extension popup.
6. Check **“Enable team sync and automatic demo imports”**, then click **Save & connect**.

Stay signed into FACEIT and keep CounterScout running. **Manually click Download demo in the FACEIT match room.** Once the download finishes, the extension automatically imports and parses it in CounterScout. No FACEIT API key is required.

### Updating

Close the old app, extract the new release, and copy your existing `user-data` folder into it to preserve your demos and settings. Reload or re-add the extension from the new folder.

The executable is unsigned, so Windows may display a SmartScreen warning. Only run files downloaded from a trusted release.
